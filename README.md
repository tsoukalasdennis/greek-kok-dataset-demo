# Greek KOK Dataset Demo

A small demo of the [Greek KOK dataset](https://github.com/tsoukalasdennis/greek-kok-dataset), focused on the car category.

**[View the live demo](https://tsoukalasdennis.github.io/greek-kok-dataset-demo/)**

This demo loads the questions and images directly from the dataset repository; it does not include a copy of the dataset.

It is a basic demonstration of the data, not an official or reliable learning tool. Please refer to the dataset repository for its structure, sources, license, and accuracy notes.
